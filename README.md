# How to connect Jane App to Claude Code, ChatGPT and any AI agent

**Yes, Claude, ChatGPT and other AI agents can work in your Jane App account.** Jane App lists no official ChatGPT or Claude app in its integration catalog. Cotlet.dev connects your own signed-in Jane App account to any AI agent, so you can ask in plain words and the AI lists your appointments and reads the wait list for you.

## What you can ask

> List all of Dr. Patel's appointments for Thursday with start times and treatment types.

> Who is on the wait list for a massage with Leah this week? Show their preferred days and times.

> How many appointments do we have tomorrow per practitioner? Flag anyone with fewer than 4.

> Show me every first visit booked between Monday and Friday next week.

> Is anyone on the wait list who could take the 3 pm physio slot with Marco on Wednesday?

## Connect in 2 minutes

Get your API key at https://cotlet.dev/app and export it as `COTLET_API_KEY`.

### Claude Code

```bash
claude mcp add --transport http cotlet https://cotlet.dev/mcp/v1 --header "Authorization: Bearer $COTLET_API_KEY"
```

### ChatGPT

Settings → Apps → add connector URL `https://cotlet.dev/mcp/v1`, then sign in with Cotlet.dev. No API key needed.

### Cursor

Copy `.cursor/mcp.json` from this repo into your project:

```json
{
  "mcpServers": {
    "cotlet": {
      "url": "https://cotlet.dev/mcp/v1",
      "headers": {
        "Authorization": "Bearer ${COTLET_API_KEY}"
      }
    }
  }
}
```

## Run it locally (stdio)

This repo is a real MCP server. It speaks MCP over stdio, lists its Jane App tools without any key, and forwards every tool call to the hosted Cotlet.dev server. The hosted URL above stays the recommended way. Use this when your client only starts local servers.

```json
{"mcpServers":{"jane-app":{"command":"uvx","args":["jane-app-mcp"],"env":{"COTLET_API_KEY":"your-key"}}}}
```

Or with Docker:

```bash
docker build -t jane-app-mcp .
docker run -i --rm -e COTLET_API_KEY jane-app-mcp
```

Tools: `jane_app_guide`, `jane_app_status`, `jane_app_open`, `jane_app_read`, `jane_app_click`, `jane_app_type`, `jane_app_close`. Without `COTLET_API_KEY` a tool call answers: "Set COTLET_API_KEY. Get a key at https://cotlet.dev/app".

## Command line

Python 3.10+, nothing else to install. From PyPI:

```bash
pip install jane-app-mcp        # or run it once: uvx jane-app-mcp connect
jane-app-mcp connect
```

Or straight from this repo:

```bash
export COTLET_API_KEY="your-key"
python3 jane_app_agent.py connect   # ready config for Claude Code, Cursor, ChatGPT
python3 jane_app_agent.py status    # is Jane App ready in your Cotlet.dev account
python3 jane_app_agent.py guide     # Jane App screens and sign-in link
python3 jane_app_agent.py read      # open Jane App, read the page, close the browser
python3 jane_app_agent.py tools     # list Cotlet.dev tools
python3 jane_app_agent.py serve     # start the stdio MCP server (same as no argument)
```

## Questions from Jane App users

**Does Jane App have an API for appointments and the wait list?**

Jane has an API for approved Technology Partners only, and clinics cannot build their own integrations. Cotlet.dev works in your own signed-in Jane App account, so your AI agent lists appointments and reads the wait list without API access.

**How do I connect Jane App to ChatGPT?**

Add Cotlet.dev as an app in ChatGPT (Settings → Apps, connector URL `https://cotlet.dev/mcp/v1`), sign in to Jane App once in your Cotlet.dev Cloud Browser, and ask ChatGPT in plain words. No code and no Jane App API key.

**Is there a way to use Claude with Jane App?**

Yes. In Claude Code run the one-line `claude mcp add` command above; in the Claude app add `https://cotlet.dev/mcp/v1` as a custom connector. Claude then works in your own Jane App account.

**Is there a Jane App MCP server?**

Jane App has no official MCP server. Cotlet.dev is a hosted MCP server that works in Jane App for you, 24/7, with Claude, ChatGPT, Cursor, Codex, n8n, Make and Zapier.
